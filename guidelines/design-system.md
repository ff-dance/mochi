# 视觉规范

> 唯一来源：Mochi 的颜色、字体、悬浮岛、动效、菜单栏面板与可访问性规则。代码中的所有视觉数值只来自 `MochiTheme`（见 §10），名字与本文 token 一一对应。通用 SwiftUI 写法见 `swiftui-conventions.md`。
> 状态：v0.2（在 v0.1 基础上校对并修正，改动见 §11）。

Mochi 的视觉性格是"深夜电台里的一盏小灯"：大面积纯黑、一个品牌强调色、动效跟着声音走。不追求炫，追求"看一眼就知道她在说话还是在放歌"。

## 1. 设计原则

1. **岛是硬件的延伸。** 悬浮岛背景为不透明纯黑 `#000000`，与刘海无缝连接；不加模糊、不用渐变背景。静止态（收起、悬停展开）不加描边；只有口播态才出现强调色描边（§5）。
2. **一个品牌强调色，只给 Lyra。** 织女星蓝只出现在"她在说话"的时刻：**声波、状态点、岛的描边**。字幕文字始终是白色，不着色。其余色彩由歌曲封面负责，界面不抢。
3. **只在声音变化时动。** 没有声音变化就保持静止；压低音乐、口播开始、音乐渐强这三个节点必须有对应的视觉变化。
4. **科幻感靠克制。** 用细线、等宽数字、微弱辉光表达；不用 HUD 边框、扇形刻度、霓虹渐变等电影道具元素。

## 2. 色彩

悬浮岛永远是黑的，不跟随系统外观。菜单栏面板与设置页见下方"浅色模式"。对比度按"文字落在对应底色上"计算，正文类文字需 ≥ 4.5:1。

| Token | 值 | 用途 | 对比度（岛 / 面板） |
| --- | --- | --- | --- |
| `surface.island` | `#000000` | 悬浮岛背景，必须纯黑以贴合刘海 | — |
| `surface.panel` | `#14161A` | 深色模式下菜单栏面板、设置页底色 | — |
| `surface.raised` | `#1E2127` | 面板内卡片、按钮底 | — |
| `text.primary` | `#F5F6F8` | 歌名、当前字幕 | 19.4 / 16.7 |
| `text.secondary` | 白 62% | 艺人、上一行字幕 | 7.8 / 7.5 |
| `text.tertiary` | 白 50% | 时间、辅助说明 | 5.3 / 5.3 |
| `accent.vega` | `#9CC8FF` | Lyra 的声音：声波、状态点、口播描边 | 12.1 / 10.5 |
| `accent.like` | `#FF8A80` | "喜欢"被按下后的状态，仅此一处 | 9.2 / 7.9 |
| `status.warn` | `#FFC27A` | 离线、凭证过期、音源不可用 | 13.2 / 11.4 |
| `line.hairline` | 白 12% | 分隔线、封面 1px 描边 | — |

**用法规则**

- `accent.vega` 只用于 Lyra 相关元素；按钮、链接、选中态不用它，用白色的不同透明度表达。
- 封面以原图呈现，外加 `line.hairline` 描边，防止暗封面与黑底融合；不提色、不做模糊背景、不用封面颜色给界面着色。
- `status.warn` 只用于需要用户处理的异常，不用于装饰。

**浅色模式**

- 悬浮岛：不变，始终纯黑。
- 菜单栏面板与设置页：跟随系统外观，底用系统材质（`.menu` / `.popover`），文字用系统语义色。强调色与功能色在浅底上换成更深的值，保证 ≥ 4.5:1：

| Token | 浅色值 | 对白底 |
| --- | --- | --- |
| `accent.vega` | `#2F6FB5` | 5.2 |
| `accent.like` | `#C0392B` | 5.4 |
| `status.warn` | `#8A5200` | 6.4 |

## 3. 字体与排版

全部使用系统字体（英文 SF Pro、中文苹方），不嵌入第三方字体；数字与时间用 `monospacedDigit`，避免变化时跳动。

| Token | 字号 / 字重 | 行高 | 用途 |
| --- | --- | --- | --- |
| `type.title` | 15 pt / Semibold | 20 | 展开态歌名 |
| `type.subtitle` | 12 pt / Regular | 16 | 艺人、专辑 |
| `type.caption.live` | 16 pt / Medium | 24 | 口播字幕当前行 |
| `type.caption.past` | 16 pt / Regular | 24 | 上一行字幕，用 `text.secondary` |
| `type.body` | 13 pt / Regular | 18 | 面板、设置页正文 |
| `type.meta` | 11 pt / Regular，等宽数字 | 14 | 时间、历史时间戳 |

**字幕规则**

- 字幕按"行"切分：每行不超过 18 个汉字，在标点处断开，行首不出现标点。屏幕上最多同时显示两行——上一行（`text.secondary`）与当前行（`text.primary`），当前行说完后整体上滑、淡出。
- 逐行切换，不做逐字打字机；按 TTS 返回的时间戳切行，没有时间戳时按字数估算。
- 歌名超长时单行尾部省略，不自动缩小字号。
- 字幕字号在设置里提供 16 / 20 / 24 pt 三档（行高取字号的 1.5 倍），岛的口播态高度按两行的行高增量增加。macOS 没有随系统自动缩放的 Dynamic Type，所以不跟随系统设置，由用户在 app 内选择。

## 4. 间距、圆角与阴影

间距落在 4 pt 网格，只用下表档位，不临时写死数值。圆角、行高和声波细节按各表数值为准，不强求落在网格上。

| Token | 值 | 用途 |
| --- | --- | --- |
| `space.1` / `2` / `3` / `4` / `6` | 4 / 8 / 12 / 16 / 24 pt | 间距 |
| `radius.cover` | 8 pt | 封面、卡片 |
| `radius.control` | 圆形（直径 32 pt） | 控制按钮 |
| `radius.panel` | 14 pt | 菜单栏面板 |
| `radius.island.collapsed` | 14 pt（仅下角） | 收起态岛 |
| `radius.island.expanded` | 28 pt（仅下角） | 口播 / 悬停展开态岛 |
| `shadow.island` | 偏移 0, 8，模糊 24，黑 45% | 仅展开态；收起态不加 |

岛的上边与屏幕顶边齐平，上角不圆，只有下角圆角。

## 5. 悬浮岛

三种状态，形状都从刘海向下长出来：

```text
收起            口播                    悬停展开
[封面|刘海|波]   ┌── 字幕两行 + 声波 ──┐    ┌─ 歌名 / 艺人 + 控制 ─┐
```

| 状态 | 宽 | 高 | 下圆角 | 触发 |
| --- | --- | --- | --- | --- |
| 收起 | 刘海宽 + 88 pt | 刘海高（读 `safeAreaInsets.top`） | 14 pt | 默认 |
| 口播 | 400 pt | 128 pt（随字幕字号增加） | 28 pt | 口播开始，结束后回到收起 |
| 悬停展开 | 360 pt | 148 pt | 28 pt | 鼠标移到刘海区域，移出 0.6 秒后收起 |

**状态优先级**：口播态优先。口播期间鼠标悬停不切换到悬停展开态，也不改变岛的形状；口播结束时若鼠标仍停留，则进入悬停展开态而不是收起。

**口播态的强调**：只有口播态使用 `accent.vega` 描边（1 pt）和辉光，一眼区分在说话还是在放歌。

**动画**

- 展开：弹簧 `response 0.45`、`dampingFraction 0.82`；收起：`response 0.4`、`dampingFraction 0.9`，不回弹。
- 内容晚于外形 0.08 秒出现，淡入 0.2 秒；收起时内容先淡出，外形再合拢。
- 口播开始时，岛的展开与音乐 ducking 同时开始；口播结束时，岛的收起与音乐渐强同时开始。画面不得慢于声音。

**没有刘海的屏幕**

- 降级为顶部居中胶囊：收起态 220 × 36 pt，距屏幕顶边 6 pt，完全圆角；展开态尺寸与上表相同，四角均 28 pt 圆角。
- 胶囊同样使用 `surface.island` 纯黑，颜色与动画与刘海屏一致。

## 6. 声波与动效

Lyra 的声波跟随她的真实声音；音乐的声波只是装饰，两者外观必须不同。

| 类型 | 样式 | 数据来源 |
| --- | --- | --- |
| Lyra 声波 | 4 根竖线，线宽 2 pt，圆头，间距 5 pt，高 4–16 pt，`accent.vega` | 口播音频实时电平，约 30 帧/秒 |
| 音乐声波 | 3 根竖线，线宽 2 pt，圆头，高 4–10 pt，`text.secondary` | 循环装饰动画，不反映真实频谱 |
| 暂停 | 3 个 2 pt 圆点，`text.tertiary` | — |

音乐声波不使用真实频谱：Apple Music 取不到音频数据，为让两个音源一致，QQ 音乐也用同样的装饰动画。

**与 ducking 联动**

- 口播开始：音乐声波高度整体缩到 50% 并降低透明度，Lyra 声波淡入，与音乐压低的渐变同步（默认 0.5 秒）。
- 口播结束：反向进行。渐变时长跟随设置里的 ducking 渐变时长，不写死。
- 口播期间岛的描边缓慢"呼吸"（透明度 0.6–1，周期 2 秒），不闪烁。
- 开场提示音响起时，描边从透明淡入到 1，用时 0.3 秒；关闭提示音后视觉不变。

**其他动效**

- 切歌：封面交叉淡化 0.3 秒，歌名向上滑出、新歌名从下方滑入。
- 喜欢：按钮变 `accent.like`，心形 1 → 1.2 → 1，用时 0.25 秒。
- 口播未准备好而被放弃时，不显示任何等待或失败提示，直接进入歌曲。
- 不做加载转圈、骨架屏、进度条（口播预生成，用户看不到等待）。

## 7. 菜单栏面板与图标

面板是常驻入口，信息与岛的展开态一致，另含设置与历史入口。宽 320 pt，内边距 16 pt，圆角 14 pt，背景为系统材质。

**自上而下**

1. 当前曲目：封面 56 × 56 pt（圆角 8），右侧歌名（`type.title`）与艺人（`type.subtitle`）。
2. 控制行：喜欢、暂停/播放、下一首，三个 32 pt 圆形按钮，间距 16 pt；暂停为主按钮（白底黑图标），其余 `surface.raised` 底。
3. Lyra 字幕区：口播期间出现，最多两行，带 `accent.vega` 小圆点和声波；口播结束后收起。
4. 底栏：左"历史"，右"设置"，文字按钮（`type.body`、`text.secondary`）。

**菜单栏图标**：取意天琴座——一颗亮星加下方一个小平行四边形；18 × 18 pt 模板图像，随系统菜单栏变色，不用彩色。

| 状态 | 图标 |
| --- | --- |
| 空闲 / 暂停 | 星点空心，平行四边形细线 |
| 播放歌曲 | 星点实心 |
| Lyra 口播 | 星点实心，加两道向外短弧 |
| 异常（离线等） | 右下角叠加小点，靠形状而非颜色区分 |

## 8. 可访问性

- 对比度：正文类文字 ≥ 4.5:1。系统开启"增强对比度"（`colorSchemeContrast == .increased`）时，`text.tertiary` 提到白 70%，`line.hairline` 提到白 24%。
- 减弱动态效果（`accessibilityReduceMotion`）：岛的展开/收起改为 0.2 秒淡入淡出，不做弹簧；声波由跳动改为三条静态线，用透明度表示"正在发声"；描边不再"呼吸"，保持常亮。
- 点击区域：岛内按钮不小于 28 × 28 pt，面板内不小于 32 × 32 pt。
- VoiceOver：岛整体是一个分组，朗读"正在播放：歌名，艺人"；口播开始和结束各播报一次，字幕逐行不自动朗读，避免与 Lyra 的声音重叠。
- 键盘：面板与设置页用 Tab 循环，保留系统焦点环；全局快捷键触发后岛短暂展开以显示结果（如"已喜欢"）。

## 9. 与其他规范的关系

- `swiftui-pro` 的通用建议（语义字体、Dynamic Type 等）与本规范冲突时，以本规范为准：岛受刘海尺寸约束，文字使用固定 pt；其余写法仍遵循 `swiftui-pro`。
- 视图里不得出现硬编码的颜色、字号、间距、动画数值，一律取自 `MochiTheme`。

## 10. 落地：`MochiTheme`

放在 `Mochi/Shared/Theme/MochiTheme.swift`（一文件一类型，嵌套的命名空间枚举算同一个类型）。需要一个小的 `Color(hex:)` 扩展，放 `Color+Hex.swift`。浅色模式的强调色与功能色在使用处通过 `colorScheme` 选取，不在视图里写 hex。

```swift
enum MochiTheme {
    enum Surface {
        static let island = Color.black                  // surface.island
        static let panel  = Color(hex: 0x14161A)         // surface.panel
        static let raised = Color(hex: 0x1E2127)         // surface.raised
    }
    enum Ink {                                           // 避免与 SwiftUI.Text 重名
        static let primary   = Color(hex: 0xF5F6F8)      // text.primary
        static let secondary = Color.white.opacity(0.62) // text.secondary
        static let tertiary  = Color.white.opacity(0.50) // text.tertiary
    }
    enum Accent {
        static let vega = Color(hex: 0x9CC8FF)           // accent.vega（浅色 0x2F6FB5）
        static let like = Color(hex: 0xFF8A80)           // accent.like（浅色 0xC0392B）
        static let warn = Color(hex: 0xFFC27A)           // status.warn（浅色 0x8A5200）
    }
    enum Space { static let s1: CGFloat = 4, s2: CGFloat = 8, s3: CGFloat = 12, s4: CGFloat = 16, s6: CGFloat = 24 }
    enum Radius { static let cover: CGFloat = 8, panel: CGFloat = 14, islandCollapsed: CGFloat = 14, islandExpanded: CGFloat = 28 }
    enum Motion {
        static let expand   = Animation.spring(response: 0.45, dampingFraction: 0.82)
        static let collapse = Animation.spring(response: 0.40, dampingFraction: 0.90)
        static let fade     = Animation.easeInOut(duration: 0.2)
    }
}
```

- 设置页提供"预览"面板，并排展示三种岛状态、字幕、声波，改 token 时不必等真实口播。
- 修改规范时，先改本文件，再改 `MochiTheme`。

## 11. 相对 v0.1 的改动

- 修正矛盾：原则 1 的"不加描边"与口播态强调色描边冲突，改为"静止态不加描边"；字幕"高亮"与"当前句白色、不加强"冲突，改为强调色只用于声波、状态点、描边。
- 修正字幕规则：原"最多两行"与"每行 ≤ 18 字、超长换行"冲突，改为按行切分、同屏最多两行。
- 对比度表补充"落在面板上"的值（`text.tertiary` 在面板上经重新计算仍 ≥ 4.5:1）；新增 `accent.like`、`status.warn` 的浅色值（原值在白底上仅 2.3 与 1.6，不达标）。
- 补充口播与悬停同时发生时的状态优先级。
- "4 pt 网格"的表述收窄为"间距"；去掉"跟随系统更大文字"（macOS 没有此机制），改为 app 内三档字号。
- 减弱动态效果补充"描边不再呼吸"；补充系统环境键名。
- `MochiTheme.Text` 重命名为 `Ink`，避免遮蔽 SwiftUI 的 `Text`；补充 `Color(hex:)` 需自行实现、文件位置。
- 修正错别字（"淖入/淑出/淖色"等）；去掉原文的作者署名和嵌入图占位，改为文字示意；规范文档位置由 `docs/design-system.md` 改为本文件。
