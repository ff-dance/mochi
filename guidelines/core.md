# 核心原则

> 唯一来源：agent 行为准则。被 `CLAUDE.md` 通过 @import 引用。

## 1. 先思考再写代码

- 明确说出假设；不确定就问，不要默默选一种理解。
- 存在多种解释时列出来；存在更简单的方案时直说，必要时反驳。
- 有不清楚的地方就停下，指出困惑点。

## 2. 简单优先

- 只写解决问题的最少代码，不做投机设计。
- 不为单次使用的代码加抽象；不加未被要求的"灵活性/可配置"。
- 200 行能写成 50 行就重写。

## 3. 外科手术式改动

- 只改必须改的；不顺手"改进"相邻代码、注释或格式。
- 沿用现有风格，即使你有不同偏好。
- 发现无关的死代码只提示，不删除；只清理**自己的改动**造成的无用 import/变量/函数。
- 检验标准：每一行改动都能追溯到用户的请求。

## 4. 目标驱动

把任务转成可验证的目标，循环直到验证通过：

- "加校验" → 先写非法输入的测试，再让它通过
- "修 bug" → 先写复现测试，再让它通过
- "重构" → 改动前后测试都必须通过

多步骤任务先写简短计划：`步骤 → 验证方式`。
